# 🎥 AI Blog Generator from YouTube Videos

This project allows users to input a YouTube video URL and receive a well-structured, AI-generated blog article based on the video's transcript. Using `pytube`, the application extracts audio from the video, transcribes it with `AssemblyAI`, and leverages `OpenAI` to create a summarized and coherent blog post. It's perfect for content creators, bloggers, or anyone looking to repurpose video content into written form.

---

## ✨ Features

- 🔗 Accepts YouTube video URL as input
- 🔊 Downloads and extracts audio using `pytube`
- 📝 Transcribes audio to text using `AssemblyAI`
- 🧠 Summarizes the transcript into a blog article using `OpenAI GPT`
- 💾 Saves blog entries in the database for future access
- 🔐 Includes user authentication system for saving/viewing blogs
- 🌐 Clean, user-friendly web interface

---

## 🚀 Tech Stack

- **Backend**: Django (Python)
- **Frontend**: HTML, CSS (Django Templates)
- **AI Services**:
  - [AssemblyAI](https://www.assemblyai.com/) for transcription
  - [OpenAI](https://platform.openai.com/) for blog generation
- **Video Extraction**: [Pytube](https://pytube.io/en/latest/)
- **Database**: SQLite (default Django database)

## 📦 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/yourusername/ai-blog-generator.git
cd ai-blog-generator
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
source .venv/bin/activate  # For Windows: .venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

Or manually:

```bash
pip install django openai pytube assemblyai
```

### 4. Set API Keys

Update your API keys either in code or securely using environment variables:

```python
# Example for AssemblyAI and OpenAI
aai.settings.api_key = "your-assemblyai-api-key"
openai.api_key = "your-openai-api-key"
```

> ✅ Recommended: Use `.env` + `python-decouple` to manage keys securely.

### 5. Run Migrations and Start Server

```bash
python manage.py migrate
python manage.py runserver
```

Now, open your browser and visit `http://127.0.0.1:8000`.

## 🧪 How It Works

1. User inputs a YouTube URL
2. Audio is downloaded via `pytube`
3. Transcript is generated by `AssemblyAI`
4. Transcript is sent to `OpenAI` to generate a blog post
5. Blog is saved in the database and shown on the frontend
